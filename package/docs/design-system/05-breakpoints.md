## Breakpoints & Responsive

| Name | Min Width | Typical Usage |
|------|-----------|---------------|
| `xs` | – (≤575px) | Mobile small |
| `sm` | 576px | Mobile large |
| `md` | 768px | Tablet |
| `lg` | 996px | Desktop – **sidebar visible, navigation horizontal** |
| `xl` | 1200px | Wide desktop |
| `xxl` | 1400px | Extra-wide |

### Key Responsive Behaviors

1. **Below `lg` (996px)**: Header nav collapses to hamburger menu, sidebar is hidden.
2. **Below `md` (768px)**: Cards switch from multi-column to single column.
3. **`sm` and below**: Full-width layout, touch-friendly tap targets (min 48px).
